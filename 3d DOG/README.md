# 3D DOG

A 3D interactive dog portfolio built with React, Three.js, React Three Fiber, and GSAP.

## Run locally

Requirements: Node.js 22 or newer.

```sh
npm ci
npm run dev
```

Create and lint a production build with:

```sh
npm run build
npm run lint
```

## GitHub Pages

Pushing to `main` builds and deploys the site to GitHub Pages. The workflow expects the repository name to be `3d-dog`; update `base` in `vite.config.js` if you use a different name. Enable **Settings → Pages → Build and deployment → GitHub Actions** in the repository.
