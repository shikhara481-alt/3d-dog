# 3D DOG

An interactive 3D dog portfolio built with React, Three.js, and GSAP.

The application and its setup instructions are in [`3d DOG/`](./3d%20DOG/README.md). Pushes to `main` automatically build and deploy the site to GitHub Pages.

The Pages workflow expects the repository name `3d-dog`. In the repository settings, select **Settings → Pages → Build and deployment → GitHub Actions**.
